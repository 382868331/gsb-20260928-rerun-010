# 机械臂离线编程平台

Python 负责机器人模型、逐采样轨迹、速度限速和碰撞计算；React/Three.js 负责姿态编辑、连杆与障碍物展示、完整运动重放和工程保存。当前不连接真实机械臂，也不向控制器下发指令。

## 功能

- 三关节 2D 串联连杆，支持途经姿态、抓取事件、放置事件和末端携带物体。
- 多个关节姿态之间做同步线性插值，检查完整途中位置而不是只查端点。
- 每段可单独配置关节速度上限；交界处按允许过渡时间和关节加速度上限检查速度突变。
- 显示采样只用于动画；安全检查使用固定的连续复核步长，并在相邻检查姿态之间做关节、连杆、末端、携带物和非相邻连杆的扫掠包络判断。
- 调大显示步长不会改变安全结论；无法精确证明安全的相邻姿态区间按危险区间处理，返回首次危险区间和局部重放窗口。
- 起终点安全但中途碰撞时返回拒绝结果、首次危险区间和完整帧；前端可只重放首次危险附近的运动。
- 携带物体在抓取后到放开前的整段运动参与碰撞判断；局部轨迹复核返回已复核段、受影响段和已失效的旧结论段，保存时保留旧方案结果及约束版本。
- 保存方案包含抓放时刻、物体定义和约束版本；保存和独立加载/重放时都会重新核对整段轨迹。
- 某一段无解时工程仍可保存为不可执行草稿，前面编辑内容不会被清空，也不会被标成可执行。

## 启动

```bash
cd backend
PYTHONPATH=.. ../.venv/bin/python -m uvicorn robot_platform.main:app --reload --port 8000
```

```bash
cd frontend
npm install
npm run dev
```

前端通过 Vite 的 `/api` 代理访问后端。

## 验证

```bash
PYTHONPATH=backend .venv/bin/python -m pytest backend/tests -q
cd frontend && npm run build
```

默认工程从 `-0.65,0,0` 运动到 `0.65,0,0`。两个端点不接触位于扫掠路径中的 `(1.75,0.12)` 圆形障碍，但第一连杆会在途中穿过障碍，因此结果被拒绝。测试同时验证第一关节速度从 `1.0 rad/s` 降到 `0.5 rad/s` 时，该段耗时从 `1.3s` 变为 `2.6s`。
